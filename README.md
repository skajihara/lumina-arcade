# Lumina Arcade — 光の遊技場

夜空をテーマにした、物理演算 × 連鎖爆破の小さなゲーム集です。
どのゲームにも「仕込む → 1手で解放 → 連鎖して全部消える」という共通の気持ちよさがあります。

## 遊び方（インストール不要）

**ブラウザで遊ぶ**：https://skajihara.github.io/lumina-arcade/ （main に入るたびに自動で更新）

**ダウンロードして遊ぶ**：
1. `play/` フォルダをダウンロードする（または [Releases](../../releases) の zip。`v` で始まるタグを push すると自動で作られる）
2. `play/index.html` をブラウザで開く（ダブルクリックでOK、オフラインで動きます）
3. 星図の光っている星座をクリック

各ゲームは HTML 1ファイルなので、`play/nova-pinball.html` などを直接開いても遊べます。

**スマホ・タブレット**：タッチの画面では、キーボードの代わりのボタン（ポーズ・時を止める・解放・戻す・ヒント・消しゴム）が下に出ます。横長の作品は横向きにすると大きく遊べます。

各作品のタイトルとポーズ画面に、動く4コマの「ルールカード」があります。

## ゲーム一覧

| ゲーム | 状態 | 内容 |
|---|---|---|
| Nova Pinball（星爆ピンボール） | 遊べる（12面＋エンドレス） | 星に当ててチャージ、満タンで爆発。星はいつもボールを引き（灯るほど重い）、爆発は渦の井戸になる。灯した星座の線を火が走る。アイテム（分裂・ブラックホール・ワームホール） |
| Echo Loop（残響ループ） | 遊べる（10面） | 10秒の時間ループ。過去の自分のボールと一緒に、同じ10秒で全部の星を爆発させる。過去の自分と同時に打つと共鳴。盤面の後ろで時計が回る |
| Stopped World（時止めの一撃） | 遊べる（10面） | 時間を止めて物体を引っぱって放し（パチンコ式、少し引くだけで強く飛ぶ）、解除の瞬間にまとめて解き放つ。止めている間は予測線。卵はひび3つで割れる |
| Event Horizon（事象の地平クレーン） | 遊べる（8面＋スコアアタック） | ブラックホールでかけらを輪に乗せて運び、解放（ホワイトホール）で星座の穴へ投げ入れる |
| Origami Cosmos（折紙宇宙） | 遊べる（20問） | 夜空の紙を折って遠い星を重ね、少ない点火で全部燃やすパズル |
| Starsand（星砂） | 遊べる（8面） | なめらかな線を引いてから Space で砂を流し、流体のように流れる光る砂を星座の器へ導く。色が混ざり、満ちた器は花火の雨になる |

星図ランチャーには、ゲームごとのクリア数と集めた★が出ます（全部クリアした星座は金の輪をまとう）。

## 共通の操作

- `T`：調整パネル（全パラメータをその場で変更、プリセット保存、JSON書き出し）
- `P` / `Esc`：ポーズ　`R`：やり直し　`M`：消音
- `Shift+B`：自動プレイ（デバッグ用）
- 新しい要素が出てくるステージでは、最初に「NEW」の図解カードが出ます
- BGM は作品ごとに違う曲（最初に画面に触れると流れ始めます。`M` で消音）

## 開発

```bash
npm install
GAME=nova-pinball npm run dev   # 開発サーバー
npm run check                   # 型チェック → 単体テスト → ビルド → ブラウザ動作確認
npm run balance                 # ボットで難易度を測定して reports/ に出力
```

- `packages/engine/`：共通エンジン（固定ステップのループ、入力記録、演出、音の合成、調整パネル）
- `games/<名前>/`：各ゲーム（`src/sim.ts` が描画なしのシミュレーション、`src/main.ts` が描画と画面。パズルは `src/solver.ts`）
- `reports/`：ボット・ソルバーで測った難易度（`npm run balance` で更新）
- `launcher/`：星図ランチャー
- `play/`：ビルド済みの遊べる HTML（コミットしている）

開発の進め方は [CLAUDE.md](CLAUDE.md)、予定は [BACKLOG.md](BACKLOG.md)、作業記録は [DEVLOG.md](DEVLOG.md)。

素材（画像・音源）は使っていません。グラフィックはコードで描き、音は WebAudio でその場で合成しています。
