# Lumina Arcade 企画・開発計画（案）

作成：2026-11-23　期間：2026-11-24〜11-30（Thinkronos凍結中の1週間）

## 1. コンセプト
**Lumina Arcade（ルミナ・アーケード）** — 夜空をテーマにした、物理×連鎖爆破の小さなゲーム集。
- 起動画面は星図。各ゲームが1つの星座になっていて、クリックで遊べる
- 共通の手触り：「仕込む → 1手で解放 → 連鎖して全部消える」
- 全作品共通：ブラウザでHTMLを開くだけで遊べる（オフライン、インストール不要）、調整パネル付き、難易度プリセット付き
- 画像・音源素材は使わず、グラフィックはシェーダーとパーティクル、音はWebAudioでその場で合成（連鎖が続くと音階が上がって和音になる）

## 3. 技術構成
- **リポジトリ**：モノレポ1つ（`skajihara/lumina-arcade`）。`packages/engine`（共通エンジン）＋`games/*`（各ゲーム）＋`launcher`
- **言語・ビルド**：TypeScript＋Vite。`vite-plugin-singlefile`で各ゲームをHTML1ファイルに出力（ダブルクリックで動く）
- **物理**：Planck.js（Box2D系）を固定タイムステップ（120Hz）で回す。乱数はシード固定
- **描画**：PixiJS（WebGL）。発光（ブルーム）、歪み、モノクロ化などのシェーダー
- **共通エンジン機能**
  - 固定ステップのゲームループ、入力の記録と再生（Echo Loopとリプレイに使う）
  - 演出キット：ヒットストップ、スロー、画面揺れ、フラッシュ、パーティクル
  - 音：WebAudioによる効果音合成と環境音楽の自動生成
  - 調整パネル（lil-gui）：全パラメータをリアルタイムで変更、プリセットをlocalStorageに保存、JSONで書き出し
  - ステージはJSONで定義、簡易ステージエディタ
- **遊び方の配布**：マージのたびに`play/`フォルダにビルド済みHTMLを置く＋GitHub Releasesにzipを添付

## 4. 自動化の仕組み
- **計画の管理**：リポジトリ内の`BACKLOG.md`とGitHub Issuesでタスク（1回の作業で終わる粒度）を管理
- **自動実行**：スケジュールされたタスクが数時間おきに起動 → バックログの次のタスクを取る → 実装 → テスト → コミット → PR作成 → CIが通ったら自動マージ → バックログ更新 → 作業ログを`DEVLOG.md`に追記
- **品質チェック（CIとPRで自動実行）**
  - 単体テスト（Vitest）：連鎖ロジック、折り畳みの座標変換、リプレイの再現性（同じ入力で同じ結果になるかハッシュで照合）
  - 動作確認（Playwright、ヘッドレス）：ビルド済みHTMLを開いて、コンソールエラーなし、ボット入力で30秒動作、スクリーンショットをPRに添付
  - 難易度測定：
    - ピンボール系：ランダム入力ボットでステージごとのクリア率を測り、難易度カーブが単調に上がるように並べる
    - パズル系：ソルバーで解けるかを検証し、最短手数と分岐数から難易度を付ける
  - 見た目の確認：スクリーンショットを毎回チェックして、崩れや地味すぎる箇所を直す
- **面白さの模索**：各ゲームで「MVP → 演出強化 → ひねり案を2〜3個試作（設定で切替）→ 一番良いものを採用」の順に進める。判断理由はDEVLOGに残す
